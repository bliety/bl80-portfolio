# BL80 Production — Marwan Elbliety

Independent multimedia production and visual storytelling portfolio featuring six YouTube films, including an Alhurra production. The website includes the official BL80 Production logo, embedded YouTube players, a section on editing/storytelling craft, and separately identified professional United Nations experience.

## Live site (after GitHub Pages is enabled)
https://bliety.github.io/bl80-portfolio/

## Publish for free
1. Visit this repository's **Settings → Pages** tab: https://github.com/bliety/bl80-portfolio/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then click **Save**.
4. GitHub publishes `index.html` automatically. It may take a few minutes the first time.

## Maintenance
All site source is in `index.html`, with the official logo embedded directly. You can edit the HTML to add titles, film descriptions, credits, or more projects. The page attempts to retrieve YouTube titles online and falls back to neutral labels if that service is unavailable.

This is an independent BL80 Production portfolio, not an official UN website.
